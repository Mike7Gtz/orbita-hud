El renderizador, muestreador, instalador, pruebas y documentación de esta distribución se escribieron para este proyecto. Las referencias siguientes inspiraron la composición aprobada por su autor:

- **Auzia Conky**, SZinedine: [publicación](https://www.gnome-look.org/p/1591612), [repositorio fuente](https://github.com/SZinedine/auzia-conky), licencia GPL-3.0. Se consultó su organización de configuración y reloj. Órbita usa un renderizador propio; no redistribuye su archivo de configuración ni sus recursos.
- **Conky ring control: 4 CPUs**, Moviuro: [publicación](https://www.gnome-look.org/p/1219641). Referencia visual de sectores entrelazados y medidores en el borde. No se obtuvo una licencia verificable del archivo antiguo y no se incorporó código ni recursos de ese paquete.
- [Clip de Shutterstock 3424930607](https://www.shutterstock.com/es/video/clip-3424930607-music-equalizer-party-4k-footage): referencia conceptual solicitada para un ecualizador radial. No se descargó, copió ni redistribuye el video. El espectro se dibuja por código a partir del audio local.
- Conky, Cairo, Python y NumPy son dependencias externas y conservan sus respectivas licencias. No se incluyen sus binarios. Se usa la fuente DejaVu del sistema.

`assets/design-approved.png` documenta el concepto visual aprobado, generado para el proyecto. `assets/preview-*.png` son capturas de la implementación con datos sintéticos explícitos. Ninguna contiene porcentajes privados de una suscripción real.

Los nombres ChatGPT, Codex y Claude identifican las fuentes de datos; el proyecto es independiente y no está afiliado a OpenAI ni Anthropic.
